# Portfólio Mobile - React Native + Expo

Aplicativo de currículo/portfólio desenvolvido em **React Native** com **Expo**, como atividade acadêmica da disciplina.  
O app apresenta informações pessoais, formação acadêmica, experiências, projetos desenvolvidos e um jogo interativo executado dentro do próprio aplicativo.

## Sobre o projeto

Este projeto é uma atualização do currículo/portfólio para a plataforma mobile, utilizando React Native com Expo.

O aplicativo possui navegação entre múltiplas telas usando **Expo Router**, seguindo os requisitos da atividade.

## Telas do aplicativo

- **Home**
- **Sobre**
- **Experiência Acadêmica**
- **Experiência Profissional**
- **Projetos**
- **Jogo**

## Funcionalidades

- Apresentação de dados pessoais e acadêmicos
- Listagem de tecnologias utilizadas
- Tela de projetos acadêmicos
- Navegação entre telas com Expo Router
- Jogo interativo executado dentro do próprio app
- Sistema de pontuação no jogo
- Upgrades no jogo:
  - Força do clique
  - Multiplicador de combo
  - Tamanho do alvo
  - Quantidade de bolas na tela
